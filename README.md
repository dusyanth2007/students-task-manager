# STUDYFLOW – Student Task Manager

**Plan better. Study smarter.**

STUDYFLOW is a modern student productivity application designed to help college students manage assignments, projects, exams, deadlines, and daily academic tasks.

## 🚀 Features

### 🔐 Authentication
- Login
- Sign Up
- Forgot Password demo
- Logout
- Basic authentication validation

### 📊 Dashboard
- Total tasks
- Pending tasks
- In-progress tasks
- Completed tasks
- Overdue tasks
- Today's tasks
- Upcoming deadlines
- High-priority tasks
- Task completion progress

### ✅ Task Management
Users can:
- Add tasks
- View tasks
- Edit tasks
- Complete tasks
- Delete tasks

Each task supports:
- Title
- Description
- Subject
- Priority
- Status
- Due date
- Due time
- Notes

### 🔎 Search & Filters
Tasks can be searched by:
- Title
- Subject
- Description

Filters include:
- All
- Pending
- In Progress
- Completed
- Overdue
- Priority
- Subject

Tasks can also be sorted by:
- Due date
- Priority
- Recently created

### 📅 Calendar
- Monthly calendar
- Tasks displayed on their due dates
- Completed task indicators
- Pending task indicators
- Overdue task indicators
- Click a date to view its tasks

### 📚 Subjects
Create and manage subjects such as:
- Data Structures
- DBMS
- Java
- Mathematics
- AI/ML

Each subject displays:
- Total tasks
- Completed tasks
- Pending tasks
- Completion progress

### 📈 Analytics
The analytics section displays:
- Total tasks
- Completed tasks
- Pending tasks
- Overdue tasks
- Completion percentage
- Tasks completed per week
- Tasks by subject
- Tasks by priority

### ⚙️ Settings
- Edit student name
- View email
- Profile management
- Logout
- Reset personal application data

### 📱 Responsive Design
STUDYFLOW works on:
- Desktop
- Laptop
- Tablet
- Mobile

The desktop sidebar changes into a mobile navigation menu on smaller screens.

---

## 🛠️ Technology

This standalone version uses:

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

The application is intentionally implemented as a **single HTML file** so it can be opened directly in a browser without installing Node.js or any dependencies.
